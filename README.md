# Relational Database Certification Projects - freeCodeCamp

This repository contains projects completed as part of the Relational Database Certification from freeCodeCamp. These projects demonstrate proficiency in database management, SQL, and bash scripting.

## 🛠 Technologies Used

- PostgreSQL
- Bash/Shell Scripting
- Git
- Command Line Interface
- VS Code

## 💻 Skills Developed

- Database design and normalization
- SQL queries and operations (CRUD)
- Table relationships management
- Data integrity and constraints
- Shell scripting
- Version control
- Command line navigation
- Database administration

## 📚 Projects Overview

### 1. Celestial Bodies Database
A PostgreSQL database modeling celestial objects including:
- Multiple interconnected tables (galaxies, stars, planets, moons)
- Primary and foreign key relationships
- Data integrity constraints
- Complex queries

### 2. World Cup Database
A database tracking World Cup tournament information:
- Shell scripting for data insertion
- Game results tracking
- Tournament statistics
- Query optimization

### 3. Salon Appointment Scheduler
An interactive appointment booking system featuring:
- Customer management
- Service scheduling
- Interactive bash script interface
- Data validation

### 4. Periodic Table Database
A chemical elements database including:
- Element properties and classifications
- Data formatting and validation
- Shell script for data queries
- Information display formatting

### 5. Number Guessing Game
A database-backed number guessing game with:
- User tracking
- Score history
- Statistical analysis
- Shell script interface
